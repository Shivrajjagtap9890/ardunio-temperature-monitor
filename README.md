 Arduino Temperature Monitor
 About
A simple temperature monitoring system made using Arduino UNO,
TMP36 temperature sensor, and 16x2 LCD.

 Components
- Arduino UNO
- TMP36 Temperature Sensor
- 16x2 LCD
- 10K Potentiometer
- 220 Ohm Resistor
- Breadboard
- Jumper Wires

 Working
The TMP36 sensor measures the temperature.
Arduino reads the sensor output and calculates the temperature
in Celsius. The result is displayed on the 16x2 LCD.

 Applications
- Room temperature monitoring
- Basic temperature measurement
- Arduino learning project
- Electronics mini project

 Software
- Arduino IDE
- Tinkercad Circuits
